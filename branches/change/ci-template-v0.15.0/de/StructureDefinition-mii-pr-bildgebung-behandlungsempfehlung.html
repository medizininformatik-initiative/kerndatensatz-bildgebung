Offizielle URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-bildgebung/StructureDefinition/mii-pr-bildgebung-behandlungsempfehlung Version: 2027.0.0-ballot.1
Active Stand: 2026-09-15 Maschinenlesbarer Name: MII_PR_Bildgebung_Behandlungsempfehlung

Empfehlung zur Behandlung

Diese CarePlan-Ressource wird verwendet, um Behandlungsempfehlungen zu erfassen.

Die Zuordnung der Datensatz-Elemente zu diesem Profil ist im Logischen Modell Bildgebung dokumentiert.

Beispiele

Beispiel einer CarePlan-Ressource mit Angaben zur passenden radiologischen Behandlungsempfehlung.

CarePlan-mii-exa-bildgebung-behandlungsempfehlung

Usages:

  • Examples for this Profil: CarePlan/mii-exa-bildgebung-behandlungsempfehlung
  • CapabilityStatements using this Profil: MII CPS Bildgebung CapabilityStatement
