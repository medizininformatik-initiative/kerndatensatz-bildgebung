Resource Profile: MII PR Bildgebung Anforderung Bildgebung

Official URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-bildgebung/StructureDefinition/mii-pr-bildgebung-anforderung-bildgebung Version: 2027.0.0-ballot.1
Active as of 2026-09-15 Computable Name: MII_PR_Bildgebung_Anforderung_Bildgebung

The profile describes a service request.

This ServiceRequest resource is used to record a request for an imaging procedure. It serves as the starting point for a diagnostic report and likewise for the acquisition of an imaging study.

The mapping of the dataset elements to this profile is documented in the Logical Model Bildgebung.

Examples

Example of a ServiceRequest resource:

ServiceRequest-mii-exa-bildgebung-anforderung-bildgebung

Usages:

  • Refer to this Profile: MII PR Bildgebung Bildgebungsprozedur and MII PR Bildgebung Radiologischer Befund
