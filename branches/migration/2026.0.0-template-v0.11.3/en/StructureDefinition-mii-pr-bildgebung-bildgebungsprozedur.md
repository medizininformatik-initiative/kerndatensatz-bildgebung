| Active as of 2026-09-01 | *Computable Name*:MII_PR_Bildgebung_Bildgebungsprozedur |

 
The profile describes a advisory for medical care. 

This Procedure resource is used to record the imaging procedure. It offers the possibility to use the contrast administration both with the diagnostic report and with the DICOM metadata.

The mapping of the dataset elements to this profile is documented in the [Logical Model Bildgebung](StructureDefinition-mii-lm-bildgebung.md).
