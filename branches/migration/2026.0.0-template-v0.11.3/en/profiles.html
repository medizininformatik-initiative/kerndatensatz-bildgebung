Profiles

This page lists the FHIR profiles of the Bildgebung module. The module's extensions are listed on the Extensions page; the complete, automatically generated list of all artifacts can be found in the artifact overview.

Where possible, the Core Dataset specifications build on international standards and terminologies — in particular the International Patient Summary. Adaptation to the general conditions of the German healthcare system is achieved by using the German base profiles of HL7 Germany.

All elements of the Core Dataset, adapted to the details and requirements of the use cases of the Medical Informatics Initiative, are described as FHIR StructureDefinitions. The rationale for adapting the FHIR profiles is explained textually beneath the respective profiles.

​Mandatory / must-support elements: For mandatory or must-support-flagged elements, please refer to the corresponding IPS rules, which also apply to this implementation guide.

The MII-wide naming conventions for FHIR resources (module names, resource type prefixes, rules for title, name, id and url) are maintained centrally in the Core Dataset wiki and are not repeated here.
