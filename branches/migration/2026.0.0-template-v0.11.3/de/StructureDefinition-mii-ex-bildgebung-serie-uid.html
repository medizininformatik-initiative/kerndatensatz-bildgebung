Extension: MII EX Bildgebung Bildnummer

Offizielle URL: https://www.medizininformatik-initiative.de/fhir/ext/modul-bildgebung/StructureDefinition/mii-ex-bildgebung-series-uid Version: 2027.0.0-ballot
Active Stand: 2026-08-27 Maschinenlesbarer Name: MII_EX_Bildgebung_Serie_UID

Die Extension ermöglicht es, den Bildnummer aus dem entsprechenden DICOM Tag auf Studien-Ebene anzugeben.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Observation

Diese Extension ergänzt die Observation-Ressource um den Bezug zur Bildserie aus der Bildgebungsstudie herzustellen. Die ID verweist hier dementsprechend auf die jeweilige Bilderserie.

Beispiele

Beispiel einer Observation-Resssource mit der Angabe zur betrachteten Bild-Serie

Observation-mii-exa-bildgebung-radiologische-beobachtung

Usage info

Usages:

  • Use this Extension: MII PR Bildgebung Radiologische Beobachtung
  • Examples for this Extension: Observation/mii-exa-bildgebung-radiologische-beobachtung and Observation/mii-exa-bildgebung-radiologische-messung

You can also check for usages in the FHIR IG Statistics
