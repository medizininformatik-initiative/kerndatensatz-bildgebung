This Observation resource is used to capture a radiological measurement. The resource is largely designed to be generic in order to represent a wide range of coded measurement results, e.g. the measurement of the diameter of a tumor or of a distance based on radiological imaging. In R4, there is not yet the possibility to reference the examined body structure via a BodyStructure, which is why this capability was imported from R5. Furthermore, the resource has been extended with the series and instance information from the imaging study in order to be able to refer directly to the respective image.
